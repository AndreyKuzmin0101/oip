# Задание DEMO — Векторный поиск по TF-IDF

## Цель

Разработать веб-интерфейс для выполнения векторного поиска по запросу.

---

## Что было сделано

1. WEB-server на Flask

2. Интерфейс на HTML + CSS с динамическим переключателем режима поиска

3. Реализована токенизация и лемматизация запроса. Запрос разбивается на токены, приводится к нормальной форме (если выбран режим lemmas), и очищается от стоп-слов.

4. Интеграция с VectorSearchEngine.

5. Косинусная мера для определения релевантности.

6. Поддержка русского языка, морфологического анализа с pymorphy3.

## Features

1. Переключатель между tokens и lemmas без перезагрузки страницы

2. Все расчёты на основе предобработанных TF-IDF индексов

3. Поиск не чувствителен к регистру и пунктуации
